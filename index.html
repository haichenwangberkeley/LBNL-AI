Indico OneStop server

Build the portal, authorize Indico access, and verify retrieval

PROMPT FOR CODEX
Help me set up a local CERN Indico meeting portal in Codex.

Start from https://github.com/haichenwangberkeley/indico-agent. Read its setup instructions
and reuse a working local checkout. Ask for my category URLs and date range. Retrieve
category/event JSON exports, agendas, speakers, and meeting links. Add filtering, caching,
and clear retrieval errors where needed.

For protected content, guide me through creating a GET-only Indico API token and storing it
securely on my computer. Never ask me to paste a secret into chat. Add the Bearer token on
the server, not in browser code. If login, consent, or an admin action is needed, give
exact manual steps and wait for me to finish; then verify access.

Run on 127.0.0.1:5050 with debug disabled. Test both the local page and an actual Indico
request; distinguish portal startup from CERN access. Open the portal and leave the source
code plus start/stop instructions.

For Claude Code: use the same prompt and local Python workflow; adapt workspace and tool
commands to the installed environment.

Mattermost channel authentication

Authorize a connector, verify the account, and read a channel

PROMPT FOR CODEX
Help me connect Codex to my CERN Mattermost channels.

Ask which team/channel I need. Inspect available plugins and reuse a working connection.
Otherwise set up a local MCP connector for https://mattermost.web.cern.ch using OAuth and
the Mattermost REST API.

Guide me through registering an OAuth application, using the connector's exact localhost
callback URL, then browser sign-in and consent. If app creation is restricted, explain what
an administrator must enable. Implement the code exchange, state check, and token refresh;
follow the server's documented PKCE support. Store secrets in the OS credential store,
never in chat, source files, or logs.

Do the implementation you can; give exact manual steps for credentials, consent, or
approval and wait for me to complete them. Verify my account, resolve the team/channel, and
read a few messages. Do not post anything. Explain how to reconnect and revoke access.

For Claude Code: register the same local connector with claude mcp add; use /mcp to inspect
it. Follow its own setup flow for Mattermost OAuth.

Zoom transcript, summary, and email

Connect Zoom and Gmail, retrieve the record, and prepare delivery

PROMPT FOR CODEX
Help me use Codex to download a Zoom transcript, summarize it, and email it.

Ask for the meeting title/date/time zone and recipient address. Inspect available Zoom and
Gmail connections and verify the signed-in accounts. If either is missing, guide me through
installation, OAuth sign-in, permissions, and any admin approval. Give exact manual steps,
wait for completion, then test access. Never ask for passwords or tokens in chat.

Find the exact meeting occurrence and retrieve the full available transcript, including all
segments. Save it as a readable .txt file with speakers and timestamps when available.
State missing coverage; do not invent dialogue or treat a partial transcript as the
complete meeting.

Create a separate topic-based summary with decisions, open questions, and action items with
owners when stated. Attach both files to a short Gmail draft for the verified recipient.
Check the attachments, show me the draft, and send only after I approve; then verify the
sent message.

For Claude Code: use compatible Zoom and Gmail MCP/API integrations; configure them with
claude mcp add and their documented OAuth flows. Do not assume Codex connections are
shared; guide any manual setup.

How the ttH video was made

A nine-minute film on the ttH measurement, fully offloaded to a Claude Code agent

  • Multi-scene acts. Five acts, each a Python scene file; the frames are rendered in parallel on all cores and encoded to MP4.
  • Cloned voice. Cloned from a 13-second reference clip, which stays on Perlmutter.
  • Generated audio. Every narration line is synthesized on a Perlmutter GPU node and checked by transcribing it back with Whisper.
  • Fully offloaded. A Claude Code agent wrote the storyboard and the code, rendered the film, and voiced the lines.
